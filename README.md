# 👓Indoor Smart Glasses for the Visually Impaired

This project presents an **IoT-powered wearable device** designed to assist visually impaired individuals with indoor navigation, object detection, and obstacle avoidance. The smart glasses integrate **ultrasonic sensors**, a **camera**, and **edge AI processing** on a Raspberry Pi 5 to deliver real-time alerts through **voice guidance**.

## 🚀Features

- **Real-time Object Detection** using YOLOv8 on Raspberry Pi  
- **Obstacle Detection** via ultrasonic sensors 
- **Fall Detection** using accelerometer module and visual feedback  
- **Voice Navigation & Alerts** for guiding users indoors  
- **MQTT Communication** using EMQX Broker  
- Fully portable and designed for **offline/edge** use

## 🧩Hardware Components

- Raspberry Pi 5 (with passive cooling)
- 5MP camera module
- HC-SR04 ultrasonic sensors (x2)
- ADXL345 accelerometer sensor module
- Audio output (buzzer/speaker)
- Power supply/battery

## 🧠Software Stack

- Python
- YOLOv8 model
- DeepSORT algorithm
- MQTT (EMQX broker)
- MediaMTX
- Firebase
- Flutter
